2. Adapted source code
--------------------------------------------------------------------------------

Portions of GED's Red Faction file-format code (RFL/RFG binary layout knowledge,
the geometry/brush/object data model, and reader/writer logic in
Ged.Core/IO and Ged.Core/Model) are derived from and inspired by REDUX
("The RED User eXperience Toolkit"), Copyright (c) 2025 Chris "Goober" Parsons,
distributed under the MIT License (https://github.com/GooberRF/redux). REDUX is
by the same author as GED; its code is reused and adapted directly under MIT.

Format layouts were additionally cross-checked against the community RFL/RFG
Kaitai Struct specifications, reverse engineered by Rafał Harabień (Open
Faction), wardd64 (Unity Faction), and Chris "Goober" Parsons (Alpine Faction
/ REDUX).

Alpine Faction (MPL-2.0) was used strictly as a *specification* for the Alpine
RFL section layouts and semantics, and for the ATX animated-texture descriptor
schema, the texture supercede chain, and the "Custom - <dir>" texture-category
behaviour. No Alpine Faction source code was copied; the layouts and semantics
were reimplemented from the documented field descriptions and format headers.

The DDS/BCn (BC1/BC2/BC3) block decoder, the TGA decoder, and the VBM decoder in
Ged.Core/IO/Tex are GED's own from-scratch implementations following the publicly
documented S3TC/DXT, Targa, and Volition-bitmap layouts. GED deliberately does NOT
depend on BCnEncoder.NET: a small built-in decoder keeps the dependency surface
minimal. The V3M/V3C mesh and VPP packfile knowledge is adapted from REDUX
(MIT, above) and the community format specs; the VPP padding rules were confirmed
empirically and against the RF.exe loader.

2b. Object-icon assets (provenance)
--------------------------------------------------------------------------------

GED ships its OWN original object-icon set: the icons drawn in the viewport for
lights, triggers, events, regions, etc. are procedurally rasterized from simple
strokes/shapes at startup by Ged.Rendering.Graphics.IconAtlas. No copyrighted
game art is copied or distributed; these are authored line/shape drawings and are
covered by GED's own license (LICENSE).

The optional Settings ▸ Viewport toggle "Use original object icons (from game
files)" (default OFF) instead composites RED's *original* icon bitmaps
(Icon_Light.tga, Icon_Trigger.tga, the Alpine Icon_AFNote.tga / Icon_AFCorona.tga
/ Icon_EAX.tga, etc.) into the atlas. Those bitmaps are read at runtime FROM THE
USER'S OWN GAME FILES through the VFS (ui.vpp / alpinefaction.vpp) — exactly the
same way GED reads any level texture. GED never ships or redistributes RED's icon
bitmaps. Icons that fail to resolve fall back per-icon to GED's own drawn cell.
